# flutter_core

Internal shared Flutter library (base screens, state holders, data layer, DI, reusable widgets, extensions, utilities).

Import:
```dart
import 'package:flutter_core/core.dart';
```

## 📖 Reference

Toàn bộ component / API của package được liệt kê trong **[`docs/REFERENCE.md`](docs/REFERENCE.md)** — đọc trước khi viết code để tái dùng, tránh tạo trùng. File này đi kèm submodule nên mọi project dùng `flutter_core` đều có sẵn (không cần gen lại).

Khi thêm/sửa component trong core → cập nhật `docs/REFERENCE.md`.
